# Dashboard preparation feature map

This map covers the preparation helpers, not the live dashboard. Use the repository root, Bash and Python 3. The HTTP fixtures use disposable OS-assigned ports and no credentials. Capture CLI action, output and exit code through the source-bound proof writer. Cleanup removes fixtures and preserves proof.

- [Wizard plan](wizard-plan.md) covers the three-stage plan and preservation of local state.
- [Interactive boundary](interactive-boundary.md) covers noninteractive refusal before browser login.
- [Local page check](local-page-check.md) covers candidate readiness and refused responses.
