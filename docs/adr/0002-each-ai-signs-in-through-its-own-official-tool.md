# Each AI signs in through its own official tool

Every bot uses its vendor's own tool with Et's own account. Claude Code uses Claude Pro, Codex uses ChatGPT, and Grok Bot uses Et's Grok plan. Credential proxies such as CLIProxyAPI, which turn a subscription login into a shared API or pool several accounts, stay out of the setup.

Anthropic's terms limit Pro and Max logins to ordinary use of Claude Code and Anthropic's own apps, and Anthropic may enforce that without notice. The builder depends on Et's only Claude account, so a ban would stop all building.
